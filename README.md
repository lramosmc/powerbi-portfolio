# Power BI Portfolio

This repository contains a curated selection of Power BI dashboards created for portfolio and learning purposes, focused on solving real business problems through data modeling, analytics, and clear storytelling.

The projects demonstrate practical experience in Sales Operations, Forecasting, Finance, and Performance Management, applying best practices commonly used in corporate BI environments.

## What You Will Find
- Business-driven dashboards focused on decision-making
- Clean data models following star schema principles
- DAX for KPIs, trends, rankings, and quality indicators
- Forecast and pipeline quality analysis
- Executive-ready design with clear and actionable insights
- Automation concepts using Power BI and Power Automate

## Project Overview

### Forecast & Pipeline Quality Dashboard
A dashboard designed to improve sales pipeline hygiene, forecast accuracy, and accountability.

Key aspects include:
- Pipeline quality KPIs
- Opportunity aging and inactivity analysis
- Qualification and forecast adjustment indicators
- New logo pipeline tracking
- Product mix visibility
- Commit and churn forecast views
- Weekly pipeline MRR evolution

This project was designed to support Sales Operations teams and enable effective 1:1 discussions with Account Managers.  
It also includes an automation concept for individualized report distribution using Power Automate.

## Tools & Skills Demonstrated
- Power BI
- DAX (time intelligence, KPIs, rankings)
- Data modeling and relationships
- Power Query for data shaping and cleansing
- Power Automate for report distribution concepts
- Dashboard design for executive audiences
- Business-oriented KPI definition and governance

## Data & Privacy
All datasets used in this portfolio are public, simulated, or fully anonymized.

No real company, customer, or confidential information is included.  
Customer and segment names are anonymized using generic labels such as Customer 1, Customer 2, etc.

Dashboards are not related to internal or client-facing systems.

## Purpose of This Portfolio
This portfolio was created to:
- Showcase real-world BI problem-solving skills
- Demonstrate understanding of business processes beyond visualization
