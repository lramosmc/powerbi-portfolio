# Power BI Portfolio

This repository presents a curated portfolio of Power BI projects built to solve real-world business problems through analytics, data modeling, and automation.

Unlike demo-style dashboards, the projects showcased here reflect scenarios commonly found in corporate environments, including multi-source data integration, large data volumes, automated refresh cycles, and report distribution workflows.

---

## Portfolio Scope

The projects in this portfolio focus on:
- Sales Operations and pipeline quality management
- Forecasting and performance tracking
- Revenue analysis and commission-related reporting
- Executive and management-level decision support
- Automation using Power BI and Power Automate

All dashboards were designed with global scalability, governance, and operational adoption in mind.

---

## Project Overview

### Forecast & Pipeline Quality
A Sales Operations–focused dashboard designed to improve pipeline hygiene, forecast accuracy, and accountability.

The project integrates data from multiple enterprise sources and applies pipeline quality KPIs such as opportunity aging, inactivity, qualification gaps, and forecast misalignment.  
It also includes automated, individualized report distribution to Account Managers using Power Automate.

---

### Sales Performance
A global Sales Performance Dashboard used as a monthly reference for Account Managers and Sales Leadership.

The project provides visibility into attainment, year-to-date sales, year-over-year comparisons, target versus actual performance, customer and new logo revenue, and commission-impacting metrics.  
A dedicated Manager View allows leadership to quickly identify top performers through ranked performance indicators.

---

## Architecture and Data Sources

The projects were built using enterprise-grade data architectures, including:
- Centralized Data Warehouses
- Direct connections to the official CRM system
- Internal datasets and SharePoint-based operational data
- Star schema data models with clear fact and dimension separation
- Automated refresh schedules aligned with business cadence

---

## Automation and Distribution

Both projects leverage Power Automate to:
- Trigger report distribution after data refresh
- Deliver formatted, role-specific emails to end users
- Reduce manual reporting effort
- Improve adoption and accountability across sales teams

---

## Data Volume and PBIX Availability

Due to the use of large datasets, multiple data sources, and corporate-grade architecture, PBIX files are not shared in this repository.

Instead, each project includes:
- Animated GIFs demonstrating dashboard interaction
- Visual walkthroughs of automation flows
- Examples of automated email delivery to end users

This approach ensures the portfolio reflects realistic BI scenarios without compromising performance, governance, or data privacy.

---

## Data Privacy

- All data shown is public, simulated, or fully anonymized
- No real company, customer, or confidential information is disclosed
- Customer and segment names are replaced with generic identifiers
- Projects shown here are not related to any internal production systems
